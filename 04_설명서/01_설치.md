# 01. 설치와 첫 실행

받은 폴더를 원하는 곳에 복사한 뒤 시작하세요. 경로에 한글·공백이 있어도 됩니다.

## 가장 쉬운 시작

- Windows: `00_시작\시작하기.bat` 더블클릭
- macOS: `00_시작/시작하기.command` 더블클릭

시작 화면에서 `[1] 환경 점검·설치`를 고르면 패키지 안의 `.venv`를 만들고 필요한 항목을 확인합니다. 폴더를 옮긴 뒤 예전 환경 정보가 남아 있어도 현재 위치의 실행 가능한 가상환경인지 다시 검사합니다.

## 필요한 것

| 항목 | 용도 | 필수 여부 |
|---|---|---|
| Python 3.9 이상 | 사진 준비와 PDF 생성 | 필수 |
| Chrome·Edge·Safari 등 | 원근·색 보정 화면 | 필수 |
| `opencv-python`, `numpy`, `Pillow` | 이미지 처리 | 시작 화면에서 설치 |
| `pillow-heif` | HEIC·HEIF 사진 | 해당 사진을 쓸 때 |
| Node.js | 색연산 파리티 검증 | 개발자만 |
| poppler | 여러 PDF 통합 | 선택 |

GPU는 필요하지 않습니다. 사진 변환과 PDF 생성은 로컬 CPU에서 실행되며 원본 사진은 외부로 전송되지 않습니다.

브라우저에서 PDF를 직접 내보낼 때만 jsPDF를 `cdn.jsdelivr.net`에서 받으므로 인터넷 연결이 필요합니다. SRI 해시로 파일 무결성을 검증하며 사진은 전송하지 않습니다. 오프라인에서는 Python PDF 내보내기를 사용하세요.

## 수동 설치가 필요할 때

macOS·Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m pip install pillow-heif
```

Windows:

```cmd
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m pip install pillow-heif
```

Windows의 자세한 설치와 오류는 [08_Windows_설치](08_Windows_설치.md)를 보세요.
