# 01. 설치와 첫 실행

## 내려받기

**ZIP** (git 없어도 됨) — [main.zip 내려받기](https://github.com/CNI-KaeSoon/presentation-photo/archive/refs/heads/main.zip)
압축을 풀면 `presentation-photo-main` 폴더가 나옵니다.

명령으로 받으려면 (Windows 10 이상은 `curl`·`tar` 내장):

```cmd
curl -L -o slidetool.zip https://github.com/CNI-KaeSoon/presentation-photo/archive/refs/heads/main.zip
tar -xf slidetool.zip
```

**git** 이 있다면:

```bash
git clone https://github.com/CNI-KaeSoon/presentation-photo.git
```

받은 폴더는 원하는 곳에 두면 됩니다. 경로에 한글·공백이 있어도, 나중에 폴더를 옮겨도 동작합니다.

## 가장 쉬운 시작

- Windows: 패키지 루트의 `시작하기.bat` 더블클릭
- macOS: 패키지 루트의 `시작하기.command` 더블클릭

기존 `00_시작` 폴더 안의 같은 이름 파일도 계속 사용할 수 있습니다.

메뉴를 고를 필요가 없습니다. 필요한 환경을 자동으로 점검·설치한 뒤 브라우저 작업 화면이 열립니다. 폴더를 옮긴 뒤 예전 환경 정보가 남아 있어도 현재 위치의 실행 가능한 가상환경인지 다시 검사합니다.

브라우저에서는 `① 사진 넣기 → ② 사진 준비 → ③ 모서리·색 보정 → ④ PDF` 순서로 진행합니다. 환경 설치나 브라우저 기동을 따로 복구해야 할 때만 패키지 루트에서 `python3 00_시작/launch.py`를 실행해 기존 CLI 메뉴를 사용합니다.

## 필요한 것

| 항목 | 용도 | 필수 여부 |
|---|---|---|
| Python 3.9 이상 | 사진 준비와 PDF 생성 | 필수 |
| Chrome·Edge·Safari 등 | 원근·색 보정 화면 | 필수 |
| `opencv-python`, `numpy`, `Pillow` | 이미지 처리 | 시작 화면에서 설치 |
| `pillow-heif` | HEIC·HEIF 사진 | 해당 사진을 쓸 때 |
| Node.js | 색연산 파리티 검증 | 개발자만 |
| poppler | 여러 PDF 통합 | 선택 |

GPU는 필요하지 않습니다. 사진 변환과 PDF 생성은 로컬 CPU에서 실행되며 원본 사진은 외부로 전송되지 않습니다.

PDF는 작업 순서의 ④ 단계에서 로컬 Python으로 만들며 사진은 외부로 전송하지 않습니다. 여러 그룹을 한 PDF로 합치는 기능에는 poppler의 `pdfunite`가 필요합니다.

## 수동 설치가 필요할 때

macOS·Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m pip install pillow-heif
```

Windows:

```cmd
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m pip install pillow-heif
```

Windows의 자세한 설치와 오류는 [08_Windows_설치](08_Windows_설치.md)를 보세요.
