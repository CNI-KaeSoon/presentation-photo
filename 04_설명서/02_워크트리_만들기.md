# 02. 워크트리 만들기

워크트리는 사진을 발표·세션별 그룹으로 나눈 `02_작업장`의 폴더 구조입니다. 한 그룹이 최종 PDF 한 권이 됩니다. 일반 사용자는 브라우저 작업 순서의 `② 사진 준비`만 누르면 워크트리 생성부터 축소본·목록 생성까지 이어집니다.

```text
02_작업장/
├── 01_첫발표/img/
├── 02_두번째발표/img/
├── 02_작업장/slide_tool/
└── worktree.json
```

이미 워크트리가 있으면 `그대로 준비`를 사용합니다. `다시 나누기…`는 그룹 이름을 바꿔 기존 보정 저장 키가 어긋날 수 있으므로, 확인 창의 경고를 읽고 필요한 백업을 먼저 내려받습니다.

## 명령으로 계획 만들기

패키지 루트에서 실행합니다.

### 촬영 간격으로 자동 분할

```bash
python3 05_스크립트/init_worktree.py \
  --src 01_원본사진 --out 02_작업장 --by-gap 20
```

사진 촬영이 20분 이상 끊긴 지점에서 새 그룹을 만듭니다.

### 일정표 기준

일정 파일은 `시작시각 이름` 형식입니다.

```text
09:00 첫발표
10:30 두번째발표
13:00 오후세션
```

```bash
python3 05_스크립트/init_worktree.py \
  --src 01_원본사진 --out 02_작업장 --schedule 일정.txt
```

### 기존 하위 폴더 또는 이름만 지정

```bash
python3 05_스크립트/init_worktree.py \
  --src 01_원본사진 --out 02_작업장 --by-subfolder

python3 05_스크립트/init_worktree.py \
  --out 02_작업장 --groups 첫발표 두번째발표
```

## 계획 파일과 이동

`02_작업장/worktree.json` v2는 `root`와 `source`를 계획 파일 위치 기준 상대경로로 저장합니다. 폴더 전체를 다른 위치나 한글·공백 경로로 복사해도 같은 구조를 찾아갑니다. 다른 Windows 드라이브처럼 상대화할 수 없는 경우에만 절대경로와 저장 방식이 기록됩니다.

그룹 이름은 브라우저 저장 키의 일부입니다. 도구 작업을 시작하기 전에는 바꿀 수 있지만, 작업 뒤에는 폴더명을 직접 바꾸지 말고 도구의 그룹 이동 기능을 사용하세요.
