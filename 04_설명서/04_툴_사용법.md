# 04. 브라우저 도구 사용법

시작 파일을 더블클릭하면 환경 준비 뒤 브라우저 도구가 자동으로 열립니다. 문제 해결을 위해 직접 실행할 때는 다음 명령을 패키지 루트에서 사용합니다.

```bash
python3 00_시작/serve_tool.py
```

브라우저 주소는 `http://localhost:8770/slide_tool/`입니다. `file://`로 직접 열면 브라우저 보안 정책 때문에 이미지 픽셀을 읽을 수 없습니다.

## 0. 작업 순서 패널

화면 상단의 `📋 작업 순서`에서 전체 과정을 이어서 실행할 수 있습니다.

1. 사진 파일을 점선 영역에 끌어놓거나 `사진 폴더 열기`로 원본 폴더를 엽니다.
2. `사진 준비`를 눌러 그룹·축소본·목록을 만듭니다. 기존 그룹을 `다시 나누기…` 전에 백업 경고를 확인합니다.
3. 아래 기존 도구에서 모서리와 색을 보정하고 완료·제외 상태를 표시합니다.
4. `PDF 만들기(고해상도)`를 누른 뒤 진행 단계와 로그를 확인하고, 완료되면 `결과 폴더 열기`를 누릅니다.

작업 중에는 `작업 취소`로 실행 중인 준비·PDF 잡을 멈출 수 있습니다. 기존 `백업 내보내기` 다운로드는 별도 오프라인 백업 수단이므로 계속 주기적으로 사용하세요.

## 1. 모서리 보정

1. 왼쪽에서 사진을 고릅니다.
2. 네 귀퉁이 핸들을 촬영된 화면 모서리에 맞춥니다.
3. `16:9`, `4:3`, `자유` 중 결과 비율을 고릅니다.
4. 카메라 위치가 같으면 경계 복사·붙여넣기로 다음 사진에 적용합니다.
5. 흐림·중복 사진은 `제외`, 검수가 끝난 사진은 `완료`로 표시합니다.

그룹 배정이 틀린 사진은 폴더를 직접 옮기지 말고 목록의 그룹 이동 기능을 사용합니다. localStorage 키가 `../<그룹>/img/<파일>` 경로이므로 작업 후 이름을 바꾸면 저장값을 찾지 못합니다.

## 2. 색보정

상단의 색보정 화면에서 밝기, 대비, 채도, 색온도, 색조, 감마, 화이트·블랙 포인트, 선명도 등을 조절합니다.

- 색을 보존하며 명암만 펴려면 `자동 콘트라스트`
- 색 틀어짐까지 정리하려면 `자동 레벨` 또는 `자동 화이트밸런스`
- `PY≈` 표시는 브라우저에서 근사 미리보기를 쓰며 최종 PDF에서 정밀 계산됨
- `Ctrl+Z` 또는 `⌘Z`로 슬라이드별 작업을 되돌릴 수 있음
- `b`로 원본과 비교하고 `R`로 현재 슬라이드의 색을 초기화

## 3. 저장과 백업

작업값은 현재 브라우저의 `localhost:8770` localStorage에 저장됩니다. 다른 브라우저, 다른 포트, 시크릿 창은 별도 저장 공간입니다.

작업 중간과 종료 전에 반드시 `백업 내보내기`를 눌러 `slide_tool_backup_<시각>.json`을 보관하세요. 이 JSON에는 모서리, 비율, 완료·제외, 색보정, 그룹 이동 정보가 들어 있고 이미지는 들어 있지 않습니다.

브라우저 PDF는 작업용 축소본 기준이며, PDF 버튼을 누를 때 jsPDF를 `cdn.jsdelivr.net`에서 받기 위한 인터넷 연결이 필요합니다. SRI 해시로 라이브러리 무결성을 검증하고 사진은 전송하지 않습니다. 오프라인이거나 배포·인쇄용 결과가 필요하면 시작 화면의 Python `[4] PDF 만들기`를 사용하세요.

## 단축키

| 키 | 동작 |
|---|---|
| `↑` `↓` | 이전·다음 사진 |
| `Ctrl/⌘+C`, `Ctrl/⌘+V` | 경계 복사·붙여넣기 |
| `Delete`, `Backspace` | 제외 전환 |
| `Ctrl/⌘+Z` | 되돌리기 |
| `b` | 원본 비교 |
| `R` | 색보정 초기화 |
| `Esc` | 스포이드·메뉴 취소 |
